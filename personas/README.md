# Example persona packs

These packs are examples of what the framework can run, not part of the
framework. Copy one, rename it, rewrite it. How: [Writing a persona](../docs/writing-personas.md).

| pack | what it demonstrates |
| --- | --- |
| `sexton` | a house host: the full file set, mood rolls, shift lines, wake aliases for mis-heard names, moderation enabled |
| `bexton` | a performer persona: band tools and generated songs |
| `lexton` | a villain persona: scheduled special-night behavior |
| `johnny`, `trixie` | guest stars sharing one TeamSpeak identity |

`HUMAN.md` is a shared tone file loaded beneath every pack on a box. Edit or
replace it to change the house style for all bots at once.

The shipped packs carry lore and in-jokes from the server they were written
for; treat that as sample content.
